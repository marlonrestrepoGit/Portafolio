02Proyecto: GastosApp

API de control de gastos personales, publicada en la nube y pensada para lo que pide la vacante.

0endpoints
0requisitos de la vacante cubiertos
0monedas en el resumen (COP y USD)

Cada usuario se registra, inicia sesión y administra solo sus gastos (crear, listar, editar y borrar). El resumen mensual por categoría se muestra en pesos y en dólares, con la tasa de una API externa. Elige un requisito de la vacante para ver cómo lo cubre:

API REST en FastAPI (Python) con documentación interactiva generada automáticamente en /docs, validación de datos con Pydantic y estructura por capas: rutas, modelos, esquemas y servicios.
Base de datos relacional con SQLAlchemy (Usuario y Gasto, relación uno a muchos). La demo usa SQLite y el motor se cambia con la variable DATABASE_URL. Integra una API pública de tasas de cambio con tiempo máximo de espera, caché de una hora y valor de respaldo si el servicio falla.
Desplegada en Render desde GitHub: cada git push redespliega la aplicación. La configuración y los secretos van en variables de entorno.
Contraseñas cifradas con bcrypt, autenticación con tokens JWT, clave secreta fuera del código, y cada usuario solo accede a sus datos (404 ante gastos ajenos). Todo cubierto con pruebas automáticas en pytest.
