GastosApp · API REST de gastos personales

      
Hecha con Python y FastAPI. Cada usuario se registra, inicia sesión y administra solo sus propios gastos. Incluye un resumen mensual por categoría en pesos (COP) y en dólares (USD), usando una API externa de tasas de cambio.

      

        
Lo que hace
    
          
  • Registro e inicio de sesión con tokens JWT
    • 
          
  • Crear, listar, editar y eliminar gastos
    • 
          
  • Resumen mensual en COP y USD
    • 
          
  • Si la API de cambio falla, usa un valor de respaldo

        
Decisiones de seguridad
    
          
  • Contraseñas cifradas con bcrypt
    • 
          
  • Clave secreta en variables de entorno
    • 
          
  • Un usuario nunca ve gastos ajenos
    • 
          
  • Pruebas automáticas con pytest
